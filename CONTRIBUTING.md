# Contributing to D-Link Mobily Management

Thank you for your interest in contributing to this project.

## Before You Contribute

Please read this file together with:
- `README.md`
- `LICENSE`
- `CLA.md`

By contributing to this repository, you agree to follow the project contribution rules and licensing model.

## Types of Contributions Welcome

Contributions may include:
- bug fixes
- documentation improvements
- UI improvements
- code cleanup
- translations
- support for additional compatible router models
- testing and issue reports

## Issue Guidelines

Before opening a new issue:
- search existing issues first;
- clearly describe the problem;
- include device model, Android version, app version, and reproduction steps when relevant;
- attach screenshots or logs if helpful.

## Pull Request Guidelines

Please try to keep pull requests:
- focused on one change at a time;
- clearly described;
- tested before submission;
- consistent with the existing project style.

When possible, include:
- what changed;
- why it changed;
- any risks or limitations;
- screenshots for UI-related changes.

## Code Ownership and Originality

You must only submit contributions that:
- are your own original work; or
- you have the legal right to contribute.

Do not submit copied code, assets, or content from third-party projects unless you clearly have permission to do so.

## CLA Requirement

Substantial code contributions may require acceptance of the project Contributor License Agreement described in `CLA.md`.

The maintainer may request CLA confirmation before merging major or legally significant changes.

## Review and Merge

All contributions are reviewed manually.
Submitting a pull request does not guarantee acceptance or merge.

The maintainer may request changes, close the pull request, or decline contributions that do not fit the project scope, quality standards, or licensing requirements.

## Commercial Scope Reminder

This project is source-available under a personal / non-commercial model.
Commercial use is not permitted without prior written permission from DEVTE.
See `LICENSE` for details.

Thanks for helping improve the project.
